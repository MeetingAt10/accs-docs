# Software Requirements

The proposed ACCS prototype will use TypeScript 5.9 and JavaScript, with React 19 for the user interface, Vite 7 for development and build preparation, TanStack Router 1 for navigation, and TanStack Query 5 for managing API requests. Development will use a patched Node.js 24 LTS release and Express 5 for the existing health API and any approved API expansion. The current API provides a health response; the remaining institutional workflows will require implementation. Git and npm will support source control and dependency management. Developers may use Visual Studio Code or another compatible editor on a maintained Windows, Linux, or macOS installation.

Users will access the prototype through a maintained browser, such as Chrome, Edge, Firefox, or Safari. The frontend will be deployed through static hosting with HTTPS, with separate API hosting and request routing when the Express service is used. In accordance with the study's scope, the prototype will use simulated enrollment lists, sample records, and frontend state management; a database will not be required for these simulated workflows. The AI assistant will require an approved model and provider, or simulated responses for prototype evaluation. Its implementation and data handling arrangements will be selected before integration. Direct connections to live QCU databases and automatic synchronization will remain outside the study's scope.

# Hardware Requirements

Development will use a computer with a modern quad-core processor, at least 8 GB of RAM, and 20 GB of free SSD space as a practical baseline. A processor with six or more cores, 16 GB of RAM, and 50 GB of free SSD space will be recommended for concurrent development tools and browser use. Users will be advised to use a dual-core computer with 4 GB of RAM and a maintained browser; 8 GB of RAM will be preferred when other applications are open. Mobile access will require a touchscreen device with a maintained browser capable of displaying the responsive interface. A stable internet connection will support access to the hosted prototype. Dedicated GPUs, biometric devices, and ID scanners will not be required within the current scope. These hardware specifications will serve as planning estimates and have not been validated through benchmarking.
