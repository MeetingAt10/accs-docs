## Decisions taken for this round (defaults, confirm with team)

- D1 Roles: Student = Student, optionally + CCS Student Organization. Faculty = Professor, optionally + exactly one of Dean / Program Chair / Adviser. Secretary, OSAS, Guidance, System Administrator are single-role accounts. CCS staff is no longer offered. System Administrator stays assignable only by the System Administrator. One Program Chair per program; one Adviser per year level (19 Nov decision, kept). Enforced in the backend; the UI mirrors it.
- D2 Permission matrix: the CCS Secretary owns it. Her toggles apply directly and are audited (no self-request). Administrator toggles become requests that the Secretary approves or rejects. Role, account, approval and audit permissions stay locked (11/20 decision kept).
- D3 Included features: bulk year/section assignment + irregular flag; unsaved-input drafts in the main input modules; click-a-date to add event/to-do; "ongoing / no specific date" incident option; react from the feed list.
- D4 Subcategory on reports is optional (meeting decision).

## Rules for every item

- Verify on current `origin/dev` first. If already fixed by qa-v4, mark `already-fixed <sha>` with evidence.
- Items claimed fixed on 11/20 but reported failing again: find why the existing fix does not hold; do not add a parallel validator.
- Validation lives in the backend with a test in `backend/tests/`; the frontend mirrors it.
- Smallest change, existing patterns, no unrelated refactors, no new dependencies unless unavoidable.
